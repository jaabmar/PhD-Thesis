\chapter*{Abstract}

Machine learning and statistical methods are increasingly used in healthcare, government, and software engineering, where accuracy alone does not make an output safe to release or reliable to act upon. This thesis develops statistical methods for three such settings: auditing observational studies with randomized trials, private release of tabular data, and copyright-safe text and code generation.

First, we study hidden confounding in observational causal inference. Sensitivity analysis asks how strong confounding would need to be to overturn a conclusion without measuring how strong it actually is, whereas randomized-trial tests only check whether any confounding exists. Combining marginal sensitivity analysis with randomized trials, we build asymptotically valid tests for confounding above a given strength and invert them into an asymptotically valid lower bound on the true confounding strength. Synthetic, semi-synthetic, and real-world experiments confirm the validity and practical utility of our tests.

Second, we study differentially private synthesis of tabular data. We propose Private Particle Gradient Descent (PrivPGD), which optimizes synthetic particles in a Euclidean embedding space to match privatized marginals. PrivPGD projects noisy signed marginals under the sliced \(1\)-Wasserstein distance and updates the particles via GPU-parallel gradient descent on a squared sliced \(2\)-Wasserstein loss. Across nine benchmarks, PrivPGD scales to large datasets and marginal workloads, preserves feature geometry, ranks among the strongest methods on statistical and downstream metrics, and supports differentiable domain constraints through private penalties.

Third, we study inference-time copyright protection for language models. We propose Copyright-Protecting Model Fusion (CP-Fuse), which combines two models trained on datasets with disjoint sets of copyrighted material. At each decoding step, CP-Fuse solves a local minimax Kullback--Leibler problem whose closed-form log-linear update downweights whichever model dominates the generated prefix. On overfitted text and code models, CP-Fuse substantially reduces verbatim and near-verbatim copying while preserving fluency and code correctness, remaining effective alongside training-time safeguards and under prefix-prompt extraction.
