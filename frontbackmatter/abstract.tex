\chapter*{Abstract}

Machine learning and statistical methods are widely used in healthcare, public policy, and software engineering, where predictive accuracy alone does not guarantee that an output is reliable or safe to release. In this thesis, we develop methods for three such settings: auditing observational studies with randomized trials, private release of tabular data, and copyright-protected text and code generation.

First, we study unobserved confounding in observational causal inference. Using randomized trials alongside marginal sensitivity analysis, we design a statistical test to detect hidden confounding above a given strength and invert it to obtain an asymptotically valid lower bound on the true confounding strength. Across synthetic, semi-synthetic, and real-world experiments, we show that the bound reliably separates negligible from substantial confounding.

Second, we study differentially private tabular data synthesis. We introduce PrivPGD, a generation method that builds synthetic datasets from privatized marginals using optimal transport and particle gradient descent. Across tabular benchmarks, we show that PrivPGD matches or improves upon existing methods, scales to large datasets and many marginals, preserves feature geometry, and supports domain-specific constraints.

Third, we study inference-time copyright protection for language models. We introduce Copyright-Protecting Model Fusion (CP-Fuse), which adaptively combines models trained on disjoint sets of copyrighted material so that no single model dominates generation and memorized passages are not reproduced. On text and code benchmarks, we show that CP-Fuse substantially reduces copying without hurting generation quality, works alongside training-time defenses, and remains robust to extraction attacks.
