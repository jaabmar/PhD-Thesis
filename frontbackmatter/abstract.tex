\chapter*{Abstract}

In healthcare, public policy, and software engineering, good predictive performance is not enough on its own: causal estimates from observational data can be confounded, shared datasets can leak personal information, and language models can copy copyrighted material from their training sets. In this thesis, we develop methods for these three problems while keeping the resulting analyses, datasets, and models useful.

In the first part, we use randomized trials alongside sensitivity analysis to quantify unobserved confounding in observational studies. We design a statistical test for confounding above a given threshold and invert it into an asymptotically valid lower bound on the true confounding strength. In synthetic, semi-synthetic, and real-world studies, this bound distinguishes negligible bias from confounding strong enough to undermine a causal claim, giving practitioners a clearer basis for trusting an observational study.

In the second part, we introduce PrivPGD for differentially private tabular data synthesis. Using optimal transport and particle gradient descent, PrivPGD constructs synthetic tables from privatized marginals. Across nine benchmarks, it scales to large datasets and many marginals, preserves feature geometry, and supports domain-specific constraints, allowing organizations to release higher-quality tabular data under formal privacy guarantees.

In the third part, we address copyright infringement in language generation at inference time. We propose CP-Fuse, which adaptively combines models trained on disjoint sets of copyrighted material so that memorized passages are not reproduced. On text and code tasks, CP-Fuse reduces copying substantially while keeping fluency and code correctness intact, works alongside training-time defenses, and resists extraction attacks, lowering copyright risk without retraining large models.

Together, these methods help make causal reliability, data privacy, and copyright protection practical without sacrificing utility.
