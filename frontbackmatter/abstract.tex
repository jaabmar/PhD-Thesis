\chapter*{Abstract}

Machine learning systems are increasingly deployed in healthcare, government, and software engineering, where accuracy alone does not ensure safe or reliable outputs. This thesis develops statistical methods to control and quantify deployment risks across three settings while preserving utility.

First, we study hidden confounding in observational causal inference. Classical sensitivity analysis asks how strong confounding must be to overturn a conclusion without measuring its level, whereas trial-based tests check only zero confounding. Combining marginal sensitivity analysis with randomized trials, we build asymptotically valid tests for confounding above a given strength and invert them into an asymptotically valid lower bound. Synthetic, semi-synthetic, and Women's Health Initiative analyses show that comparing this bound with observational critical values separates substantial confounding from negligible bias.

Second, we address differentially private tabular data synthesis. We introduce Private Particle Gradient Descent (PrivPGD), replacing graphical-model sampling with particle optimization in a Euclidean embedding space. PrivPGD projects noisy signed marginals under the sliced \(1\)-Wasserstein distance and updates particles via GPU-parallelizable gradient descent on the squared sliced \(2\)-Wasserstein loss. Across nine datasets, PrivPGD scales to large workloads, preserves feature geometry, performs competitively on downstream and statistical metrics, and enforces differentiable constraints via additive private penalties.

Third, we study inference-time copyright protection for language models. We introduce Copyright-Protecting Model Fusion (CP-Fuse), combining two models trained on disjoint protected corpora via a local minimax Kullback--Leibler problem tracking prefix likelihoods at each decoding step. Its closed-form log-linear rule adaptively downweights the model dominating the prefix. On overfitted text and code models, CP-Fuse substantially reduces exact and approximate copying while preserving fluency and correctness, wraps training-time safeguards, and resists prefix-prompt extractions.

Across these settings, calibrated quantitative methods under explicit structural assumptions provide practical risk control without sacrificing utility.
