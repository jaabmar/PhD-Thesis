\chapter*{Abstract}
[GENERALLY ASBTARCT OK BU THE PARAGRAPH FOR EACH CHAPTER COULD BE SLIGHTLY SHORTER]
Machine learning and statistical methods are increasingly used in healthcare, government, and software engineering, where accuracy alone does not make an output safe to release or reliable to act upon. This thesis develops statistical methods for three such settings: auditing observational studies with randomized trials, private release of tabular data, and copyright-safe text and code generation.

First, we study hidden confounding in observational causal inference. Sensitivity analysis asks how strong confounding would need to be to overturn a conclusion but does not measure how strong it is, while tests based on randomized trials only check whether any confounding is present. Combining marginal sensitivity analysis with randomized trials, we build asymptotically valid tests for confounding above a given strength and invert them into an asymptotically valid lower bound on the true confounding strength. Synthetic, semi-synthetic and real-world experiments confirm the validity of our tests. 

[DONT SAY WE REPALCE SIMPLY WHAT WE PROPOSE]Second, we study differentially private synthesis of tabular data. We introduce Private Particle Gradient Descent (PrivPGD), which replaces sampling from a graphical model with particle optimization in a Euclidean embedding space. PrivPGD projects noisy signed marginals under the sliced \(1\)-Wasserstein distance and updates the particles by gradient descent on the squared sliced \(2\)-Wasserstein loss, which parallelizes on GPU. On nine datasets, PrivPGD scales to large datasets and many marginals, preserves feature geometry, ranks first or second in most metrics and datasets, and enforces differentiable constraints through additive private penalties.

Third, we study inference-time copyright protection for language models. We introduce Copyright-Protecting Model Fusion (CP-Fuse), which combines two models trained on data containing disjoint sets of copyrighted material. At each decoding step, CP-Fuse solves a local minimax Kullback--Leibler problem that tracks prefix likelihoods. The solution has a log-linear closed form that downweights the model dominating the prefix, and its weights are chosen by grid search. On overfitted text and code models, CP-Fuse substantially reduces exact and approximate copying while keeping fluency and code correctness close to those of the overfitted models. It can also be applied on top of training-time safeguards, and its protection remains largely intact under prefix-prompt extraction.
